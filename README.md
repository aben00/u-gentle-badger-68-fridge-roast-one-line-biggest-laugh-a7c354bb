One line, at most 200 characters, roasting a smart fridge — written by a deterministic Node program for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty ($5 in USDC).

## The entry

> My smart fridge locked the freezer until I accepted its new terms and conditions — my ice cream is now held hostage by a EULA.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (override the directory with `OUTPUT_DIR`).
